# Git & GitHub Starter

My first project for learning **Git** and **GitHub**, made in the *AI Software Engineer* course at STEM Link.

## What I learned

- Tracking a folder with `git init`
- Saving changes with `git add` and `git commit`
- Viewing history with `git log --oneline`
- Uploading to GitHub with `git push`

## How to get a copy

1. Install Git
2. Run `git clone https://github.com/NadevSJ/git-github-starter.git`
3. Open the folder in VS Code
